# Changelog

## 0.1.0 (unreleased)

First standalone release, extracted from the surfalize webapp's validation suite.

**Spec 1.0.0** (`spec/`): 97 gauges, 549 cases (463 core, 54 operators, 32 extension).

- Each case states its standards, its method, the literature it is taken from (`cite`,
  with a bibliography in `references`), the analytic reference on the continuous
  surface and, where one exists, the exact value for the sampled gauge, and a tolerance
  with its basis.
- Formulas are LaTeX math (ASCII, no delimiters); prose is kept separate (`text`).
- Angles follow ISO 25178-2:2021: Std counter-clockwise from +x with y up the map.
- JSON Schemas for the spec and for result files.
- Generated by a Python generator (`generator/`, numpy only) that derives every
  reference value.

**Packages** (`js/` on npm, `python/` on PyPI), one API in two languages:

- gauge builders checked against the spec's fingerprints; `Runner` (one case at a
  time) and `run` (a whole selection, by tier, domain, group or id) through a binding;
  array measures evaluated by softgauge itself; the judge.
- `softgauge report`: result files → JSON / CSV / LaTeX, byte-identical from both
  packages.
- Python only: pytest helper (`softgauge.testing`) and `softgauge export` (SDF via
  sdfio, with JSON sidecars).
